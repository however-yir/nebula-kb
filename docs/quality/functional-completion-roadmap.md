# NebulaKB Functional Completion Roadmap

本清单把产品完成度和功能补齐建议转成可验收 backlog。它不是一次性声明 300 个功能已经实现，而是用于持续推进、排期、验收和 CI 追踪的项目资产。

## 使用方式

- `P0`：影响主演示链路、权限安全、数据正确性或发布阻断。
- `P1`：影响核心用户体验、运营闭环、可观测性或企业交付质量。
- `P2`：增强项、效率项、文档完善项或长期演进项。
- 每个条目进入实现前必须补充负责人、验收方式和自动化测试策略。

## 完成度判定

| 阶段 | 标准 | 建议门槛 |
| --- | --- | --- |
| Demo Ready | 本地可跑通登录、知识库、上传、检索、问答、反馈、运营大盘 | P0 演示项完成 |
| Beta Ready | 核心功能可被真实团队试用，失败可恢复，指标可解释 | P0 清零，P1 过半 |
| Production Ready | 权限、安全、备份、监控、CI、回滚和非功能测试满足发布要求 | P0/P1 清零 |
