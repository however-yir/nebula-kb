# NebulaKB Demo Knowledge Sample

这组样例用于演示 NebulaKB 的知识资产生命周期：

1. 导入文档到知识库。
2. 解析正文并生成切片。
3. 建立检索索引。
4. 发起问答并返回引用。
5. 记录人工反馈。
6. 回看低质答案并生成治理动作。

## 文件说明

| 文件 | 用途 |
|---|---|
| `01-import-governance.md` | 文档导入、解析失败、治理责任和 SLA |
| `02-search-feedback.md` | 检索问答、引用返回、反馈评分 |
| `03-operations-metrics.md` | 知识命中率、低质答案率、未命中问题等指标口径 |
| `99-broken-scan.txt` | 解析失败样例，包含 `[PARSE_ERROR]` 标记 |
| `manifest.json` | 演示脚本读取的知识库、问题和反馈样例 |

## 推荐演示问题

- 解析失败后应该如何处理？
- 问答答案为什么必须返回引用？
- 低质答案率如何计算？
- 火星基地餐饮报销规则是什么？

最后一个问题故意没有命中，用来展示空结果兜底和未命中问题沉淀。
